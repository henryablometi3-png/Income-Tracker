## 🚀 How to Get This on GitHub (Step by Step) 1. **Create a GitHub account** (if you don't have one) at [github.com](https://github.com) 2. **Create a new repository**: - Click the **+** → **New repository** - Name it `income-tracker` - Set to Public, click **Create** 3. **Upload your files**: - On the repo page, click **Add file → Upload files** - Drag `index.html`, `style.css`, `script.js`, `README.md` - Click **Commit changes** 4. **Enable GitHub Pages**: - Repo → **Settings → Pages** - Branch: `main`, folder: `/root` → **Save** - Wait 1 min → your site is live! ## 🔑 Key Concepts to Learn From This | Concept | Where It's Used | |---|---| | **Flexbox** | Navbar, cards layout | | **Fixed positioning** | The "IT" tab & sliding panel | | **CSS transitions** | Panel slides via `right` change | | **localStorage** | Saving data without a server | | **Event handlers** | `onclick` functions | ## 💡 Next Steps to Add - **Real login** — use Firebase Auth (free) - **Charts** — add [Chart.js](https://www.chartjs.org/) - **Categories** — Salary, Gig, Scholarship, Allowance - **Monthly filter** — filter entries by month Want me to extend any part — like adding charts, a login screen, or splitting into a multi-page site?
